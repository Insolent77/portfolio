# INS — Creative Developer

Одностраничное портфолио в тёмной стальной визуальной системе. Сайт работает без сборки и внешних зависимостей.

## Состав

- постерный hero с увеличенным персональным портретом и градиентным растворением краёв;
- карточки подхода и стека;
- проекты Alex Educator и Git Time Machine;
- анимации появления, параллакс, magnetic-ссылки и интерактивные project-card;
- адаптивные desktop/mobile-композиции;
- поддержка `prefers-reduced-motion`.
- переключение EN / RU с английским по умолчанию;
- три сохраняемые темы: dark, light и mixed.

## Запуск

```powershell
python -m http.server 8000
```

Откройте `http://localhost:8000`. Параметр `?qa=1` отключает loader и reveal-задержки для визуального тестирования. Для изолированной проверки можно добавить `lang=en|ru` и `theme=dark|light|split`.

## Файлы

- `index.html` — контент и структура;
- `styles.css` — дизайн-система, адаптив и CSS-анимации;
- `script.js` — loader, reveal, меню, параллакс и интерактивность;
- `assets/ins-portrait.png` — подготовленный hero-портрет.
