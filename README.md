# INS — portfolio website

Одностраничное портфолио веб-разработчика с акцентом на понятную ценность, кейсы и обращение в Telegram. Сайт не требует сборки и внешних библиотек: достаточно загрузить файлы на GitHub Pages или любой статический хостинг.

## Что входит

- конверсионный первый экран с чётким оффером и двумя сценариями действия;
- PNG-портрет с полностью прозрачным фоном, без градиентного растворения краёв;
- кейсы Alex Educator и Git Time Machine в формате «задача → решение → результат»;
- блок услуг с ценовыми ориентирами;
- прозрачный процесс работы и блок преимуществ;
- усиленный контактный экран и фиксированная CTA-кнопка на мобильных;
- русская и английская версии;
- тёмная и светлая темы с сохранением выбора;
- адаптация под телефон, планшет, ноутбук и широкий экран;
- базовые SEO/Open Graph-метаданные и обложка для соцсетей;
- доступная навигация, `prefers-reduced-motion` и управление с клавиатуры.

## Запуск локально

```powershell
python -m http.server 8000
```

После запуска откройте `http://localhost:8000`.

Для визуальной проверки можно использовать параметры:

- `?qa=1` — отключить загрузчик и задержки анимаций;
- `?lang=ru` или `?lang=en` — выбрать язык;
- `?theme=dark` или `?theme=light` — выбрать тему.

## Структура

- `index.html` — семантическая структура, контент и метаданные;
- `styles.css` — дизайн-система, адаптив и анимации;
- `script.js` — язык, тема, меню и интерактивность;
- `assets/ins-portrait-transparent.png` — портрет без фона;
- `assets/og-cover.png` — обложка для публикации ссылки в соцсетях;
- `favicon.svg` — иконка сайта.

## Публикация на GitHub Pages

Загрузите содержимое папки в корень репозитория, затем откройте `Settings → Pages`, выберите `Deploy from a branch`, ветку `main` и папку `/ (root)`.
